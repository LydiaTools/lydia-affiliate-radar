# Lydia 推广雷达

给中国大陆个人推广者使用的跨类目活动研究、个人链接、渠道内容与佣金复盘工作台。当前 v0.1.1，2026-10-20。

当前先使用活动筛选，无需联盟或收款账户。首页比较公开佣金、申请门槛、付款条件与证据；在详情收藏，回到“我的候选”集中比较。收藏保存在本机，包含在业务JSON备份中；收藏不改变资格、分数或获批状态。

## 启动

需要 Node.js 22.13 或以上，无需安装任何第三方依赖。

```sh
npm start
```

打开 `http://127.0.0.1:8876`。终端按 Control+C 退出。仅监听本机，不创建系统常驻服务或定时任务。启动时默认刷新超过24小时或未读的信息源，可在设置关闭。

```sh
npm test
npm run collect -- affiliatejob-feed affplus
```

`LYDIA_PORT` 可改端口，`LYDIA_DB` 可指定同一台机器的运行数据库位置。数据库应放内置盘，不能把活动数据库放入云同步目录。

## 用户操作顺序

1. 发现活动：按类目、币种、奖励类型、提现门槛和研究优先级查找；收藏后可在“我的候选”比较。
2. 查看来源：回查官方条款、采集时间和变化记录。选定活动、准备开通时再展开详情的“选定后再开通与取链”，记录大陆个人资格、本人获批和付款方式的官方/后台依据。
3. 我的链接：导入本人后台链接，识别推荐码与归因参数，逐字保留原链接。
4. 推广内容：按推荐渠道生成可编辑规则草稿；可选接入兼容文案接口，调用后标记为模型草稿。不会发布内容。
5. 归因复盘：建立渠道计划，导入联盟订单或同步Awin，分开核对待审、批准、平台付款和银行到账。
6. 信息源：查看真实刷新、失败、网页变化、自动分类候选和运行记录。

## 数据口径

- 内置15个官方来源研究档案，包含国内外9类活动。京东、淘宝、美团目前主要确认官方入口，实时商品佣金和本人结算规则仍需登录/接口核验。
- 27个来源；本轮采集297条目录候选，其中18条被目录标为无公开活动。第三方佣金与Global地区标签不是官方认可、审核概率或大陆付款证明。
- 研究优先分是启发式排序。固定奖励取已知下限，比例取下限；金额排序仅限单一币种。未公开的审核通过率显示未知，本人申请统计单列且标样本数。
- 来源抓取成功仅表示网页可读取。首次读取建立基线，后续条款文字变化进入复核，不自动改佣金。快照不会使未知字段自动成为已验证。
- Awin促销折扣、优惠码、佣金、推广者邀请码分别记录。促销优惠不是推广佣金。
- 点击记录是HTTP请求，不是独立真人；已识别的预览、爬虫排除。跨域成交需联盟订单或回传，不能由UTM自行推断。
- `bank_received`必须有凭据记录。退款/拒付从当前有效佣金剔除。这里不是银行余额或完整会计现金流账，退款后的真实银行流转仍应凭证核账。
- 初期少于30次有效点击或5笔确认订单时不宣布渠道胜出；策略建议不自动买量或改预算。

## 已实现的Awin接口

通过本人Publisher ID和Token授权后，服务端使用Bearer认证：

- 读取活动：`POST /publisher/{publisherId}/promotions`，分页，地区不默认限制为CN，因为商品可售地区不同于推广者资格。
- 取链：`POST /publishers/{publisherId}/linkbuilder/generate`。
- 查询订单：`GET /publishers/{publisherId}/transactions/`，每次最多31天，默认按amendment时间读取。

创建Awin渠道计划时再次向官方取带计划专用clickref的链接。只有clickref和广告主都匹配时才归因。未知订单结构/未匹配订单不猜测分配。

接口按2026-10-20官方文档实现并通过契约模拟测试，**尚未用本人真实账户验证**。其他联盟先支持后台链接导入与CSV；各平台API需要独立权限适配。

## 运行数据、备份与凭证

- `data/radar.sqlite`：内部SQLite业务数据、快照与审核历史；可能存在配套`-wal`、`-shm`文件，正常运行期间不要单独移动数据库。
- `data/private-config.json`：可选API凭证，目录权限700、文件权限600；仅本机，不回显到页面、数据导出或Git。
- 页面设置可导出不含密钥的业务JSON。该导出包含个人链接和订单，按个人数据保存。还未提供自动导入恢复界面。
- `work/`：开发临时文件，不用于交付或备份。生产数据和临时文件均被Git忽略。

## 验证范围与缺口

27项自动化测试覆盖收藏的跨重启持久保存与资格分离、兑现门禁、过期/非现金、不混币种、订单去重/回滚/退款、银行凭据、API密钥不回显、跨站写入保护、DNS地址检查、真实URL保留、Awin协议和目录采集。另做真实公开来源采集、桌面与手机浏览器UI检查。

尚缺：本人联盟批准与真实取链、具体大陆收款到账、真实订单回传样本、文案模型实调用、可公开访问的归因服务。当前`/r/...`仅为本机测试路径，不能直接发给公众，也不因填一个域名就宣称部署成功。

## 当前公式

默认权重：奖励35、公开申请门槛25、付款条件30、证据时效10。奖励分为非收益预测的启发式量尺：固定下限使用对数缩放，比例下限使用线性缩放；不同模型的综合分只能作为研究队列。付款分考虑最低额、方式、冻结期和额外引荐客户条件。地区、主体、本人资格、提现门槛未知、条款过旧/变化、非现金、活动到期均单独阻断执行，不会被分数抵消。
